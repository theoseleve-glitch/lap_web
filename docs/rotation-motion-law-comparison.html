New Subject / Motion Profile Study

Four speed charts for the same 90 deg move in 100 ms

Each chart shows output speed versus time for one motion law. The average output speed stays fixed at 150 RPM because the move angle and move duration are fixed, while the peak speed depends on the law.

Target angle 90 deg
Move duration 100 ms
Average speed 150 RPM
Output 4 separate charts

Step

Ideal constant speed during the move with instantaneous start and stop. It is useful as a reference shape rather than a directly physical command law.

Triangular

Symmetric linear ramp up and ramp down over 50 ms each. This gives the highest peak speed among the finite-acceleration profiles here.

Trapezoidal

Symmetric 25 ms acceleration, 50 ms cruise, and 25 ms deceleration. It trades lower peak speed for steeper ramps than the triangle.

S-curve

Smooth minimum-jerk quintic law. It removes acceleration discontinuities while still requiring an elevated peak speed for the same 100 ms move.

All four charts use the same axes so the shapes can be compared directly. The dashed horizontal line marks the fixed 150 RPM average speed; the shaded region is the active 0 to 100 ms move window.

Triangular law

Linear acceleration to the midpoint, then linear deceleration. The shorter high-speed dwell drives the peak speed up to 300 RPM.

Speed [RPM] vs time [ms]

The symmetric ramp shape concentrates more of the motion near mid-stroke, which pushes the peak speed highest.

Trapezoidal law

Faster ramps to a lower peak speed, followed by a cruise segment. This example uses a 25 / 50 / 25 ms split.

Speed [RPM] vs time [ms]

The 200 RPM plateau lowers the peak speed compared with the triangular law by spending more time at cruise.

S-curve law

Smooth minimum-jerk profile with a rounded crest. It softens the transitions, but it does not minimize the absolute peak values under the same timing constraint.
