KNOWN RISKS & GOTCHAS

  • stripe module is Docker-only (not in requirements.txt) — billing will fail outside Docker
  • Docker deploy requires build, not just restart — source is COPY'd into image
  • SET LOCAL for RLS resets on mid-request conn.commit()
  • Auth token in-memory (not localStorage) — page refresh requires silent refresh via httpOnly cookie
  • Free report 1-use limit is client-side only (localStorage) — no server-side enforcement
  • Legacy HTML routes (weekends, drivers, karts, analytics, predictions) still registered — won't break anything but accessible via URL
  • data_v2.py is 57KB — functional but large, split in V2
