# Elevation-Grade Correction — Longitudinal Shadow Experiment

**Purpose.** Measure whether confidence-gated elevation-grade correction moves IMU longitudinal accel toward GPS-derived `dv/dt_g` by more than noise. No production correction is enabled. Bronze and Silver are unchanged.

**Product boundary.** The repo does not expose a bronze longitudinal demand product analogous to `lateral_demand.excited_p90`. These metrics are computed on per-lap IMU samples directly; they are diagnostic, not canonical.

**Correction formula** (pinned by `test_longitudinal_grade_shadow.py`):
```
corrected_along = raw_along_imu + sin(grade_elevation_rad)
   applied where grade_elevation_confidence(s) ≥ 0.6; else pass raw through.
```

**Metric.** `rmse` = RMSE(channel − dv/dt_g). Smaller is better. `bias` = mean(channel − dv/dt_g). Closer to 0 is better.
