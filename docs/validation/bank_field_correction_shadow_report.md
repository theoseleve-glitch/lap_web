# Bank-Field Correction — Shadow Experiment

**Purpose.** Measure whether confidence-gated correction using the Gold-alpha-shadow bank field moves observed lateral demand toward GPS centripetal better than either raw or the per-sample correction.

**Three channels compared:**

- `raw` — RaceChrono `*calc` lateral G (unchanged).
- `per_sample` — raw − sin(bank_per_sample) using the legacy `estimate_road_attitude` gated on its own per-sample quality.
- `bank_field` — raw − sin(bank_field(s)) applied only where `bank_confidence(s) ≥ 0.6`. Elsewhere the raw value passes through unchanged.

**Reference.** Signed GPS centripetal `v²κ/g`. `cal_bias` = median(|channel| / |v²κ/g|) on in-corner samples. Closer to 1.0 = better alignment with the one external reference we have.

**Invariant.** No bronze/silver output is modified. No active correction path is enabled.

## 3. Verdict

**Wins across regimes:** bank_field wins 3/7 regimes.

**all_valid summary:** cal_bias 0.853 (raw) → 1.132 (per-sample) → 0.904 (bank_field).
**all_valid RMSE:** 0.280 → 0.307 → 0.283 G.

**Verdict: BETTER THAN BOTH.** Confidence-gated bank-field correction moves cal_bias closer to 1.0 than either raw or per-sample, without increasing RMSE.
